Los archivos de `original/` **no se editan nunca**. Las versiones normalizadas
están en `normalized/` y las genera `scripts/analyze_reference.py` (`make analyze`):
un SVG por letra, en UPM de Montserrat y con la línea base en 0. Cada SVG contiene el
esqueleto (relleno) y el contorno visible (relleno ∪ trazo), además de `measurements.json`.

Fuente base (ver `../docs/analisis-logos.md`): **Montserrat**, OFL 1.1,
https://github.com/JulietaUla/Montserrat, commit fijado `555facfb2a18c72c3c0380f0d9c0f060453a9058`.
